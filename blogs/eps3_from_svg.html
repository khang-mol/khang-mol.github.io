Imagine this oddly specific scenario: As an (an)organic chemist, you are trying to write your thesis / lab report in LaTeX. Since you worked with a lot of molecules, numbering your chemical compounds has grown quite tedious. On your quest to save your sanity, you stumbled upon the chemnum package. After saving your compounds (which you have drawn in ChemDraw) as EPS files, you followed the documentation to your needs.

With the cloud-based editor overleaf, you encounter no problems. The next time, you switch to your favorite IDE of choice VSCode and... the package doesn't work? To troubleshoot, you again refer to the documentation for chemnum and under the section "8 Replacing Tags in eps or ps Files", you see this snippet:

"For the actual replacement please make sure that you compile with shell-escape enabled. If you compile with pdflatex you probably also need auto-pst-pdf [RG09] loaded. In subsequent runs load it with option off when you turned off shell-escape."

This was something, that overleaf handled for you automatically. Even after following each step, the code still doesn't work. My guess is that ChemDraw saves as EPS level 2, while you need level 3.

EPS level 3 from the terminal with Inkscape

You will just need the following software/skills:

  1. Inkscape (necessary, but free)
  2. Basic understanding of paths and the terminal (nice to have)

One solution to get EPS level 3 file formats would be to paste the compound into your graphics program of choice and export from there. The following will discuss the Free and open source vector graphics editor Inkscape (Illustrator may work too). While this method works, a faster way would be to use the command line.

First, we will save the compounds made in ChemDraw as an SVG file. This will be converted to EPS with a simple command. As per the documentation, this may be achieved with the following example:


          inkscape --export-filename=[filename_out].eps [filename_in].svg
Depending on where you saved your inkscape application, you may get an error like this: 

                -bash: illustrator: command not found

If you have saved the application in the Applications folder, then you can replace the command inkscape with the full pathname:


              /Applications/Inkscape.app/Contents/MacOS/inkscape
                  --export-filename=[filename_out].eps [filename_in].svg

Since this is quite tedious to type out, I recommend to set up a path variable. For this, go to your "/Users" folder in Finder (can be done with "Cmd+Shift+G" and typing the folder name). Then click on your username (with the house icon). Here, search for the document called ".bash_profile". The dot "." at the beginning of the filename indicates, that the document is hidden by default. First, you will have to display it with the shortcut "Cmd+Shift+.". Then, insert the following line:


              export PATH="/Applications/Inkscape.app/Contents/MacOS:${PATH}"

To update ".bash_profile", you either type source ~/.bash_profile into the terminal or open up a new terminal. Now, everytime you use the inkscape command, the terminal will always use the full pathname. The output file will now be compatible with the chemnum package for your LaTeX session.

Automation with python

Since you will handle a plethora of compounds, I wrote a short (and probably amateurish), but useful python script. You can find it below or on my GitHub here.


          #!/usr/local/bin/python3
          # svg2eps.py (script name)
          import subprocess
          import pathlib
          def main():
              file_path = pathlib.Path.cwd()
              # rglob for including subdirectories
              for file in file_path.glob('*.svg'):
                  filename = pathlib.Path(file).stem
                  subprocess.run(['inkscape', '--export-filename='
                      + f'{filename}.eps', f'{filename}.svg'])
        
          if __name__ == '__main__':
              main()

The script takes the current path of your terminal session, searches for every file with the .svg extension and runs inkscape to convert them into .eps files. Save the script wherever you want like a dedicated scripts folder (just better not change it) and create a path variable again for convenience. To get the full path, select a folder in Finder and press "Cmd+alt+c". As an example:


          export PATH="[full_path_to_folder_with_svg_files]:${PATH}"

This should also make sure, that all your future scripts inside this folder have a shortened command.

If you type ls -l into your command line inside your script folder, you may get this for your script: -rw-r--r--.

So don't forget to make your scripts executable with the command 'chmod' (change mode) onto 'u+x', which instructs the system to give the user (u) execute (x) permissions for a file. 


              chmod u+x svg2eps.py

ls -l in your command line should now give -rwxr-xr-x as a result.

Change your directory into your folder with all your SVG files you want to convert. Now simply type in


          python svg2eps.py

and all your SVG files inside your current folder should be converted to EPS level 3 files, ready to be used with chemnum! But then you realize that the package is no longer maintained and you should have just used Word for organic chemistry in the first place...
